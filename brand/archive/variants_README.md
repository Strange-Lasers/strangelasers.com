# Strange Lasers logo variants

The primary hot-metal logo remains unchanged in the parent directory. This directory contains six color studies of the original bent-beam mark and two alternate designs.

## Original mark colorways

- `logo-acid-green.svg`: acid lime and emerald
- `logo-amber-cobalt.svg`: optical amber and cobalt
- `logo-uv-infrared.svg`: ultraviolet and infrared
- `logo-monochrome-red.svg`: adjacent red wavelengths
- `logo-ice-blue.svg`: cool blue monochrome
- `logo-copper-teal.svg`: oxidized copper and teal

Each logo has a corresponding `mark-*.svg` square avatar source.

## Alternate designs

- `logo-spectrum-s.svg`: one continuous curved beam draws the S
- `logo-singularity.svg`: two curved beams orbit a central singularity

The `singularity-studies/` directory expands the singularity direction into six related symbol concepts, each with a horizontal logo and square mark.

The `oculus-colorways/` directory holds eight palette-only studies of the Oculus eye geometry.

The `oculus-shortlist/` directory keeps Abyss and Moon Crimson alongside six darker observatory-inspired palette studies.

Run `node generate.mjs` after changing the primary SVG geometry or a palette. The generated SVGs are self-contained and retain outlined wordmarks.
