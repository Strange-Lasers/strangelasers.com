# Strange Lasers exploration archive

This flat archive preserves the design directions that preceded the [production identity](../README.md). Filename prefixes retain enough provenance to group related assets without restoring the former nested directory tree.

## Exploration groups

| Prefix | Contents |
|---|---|
| No prefix | Original angular mark, early palette comparison, and endpoint studies |
| `variants_` | Colorway, Singularity, Oculus, palette-shortlist, and endpoint explorations |
| `round1_` | Broad rendering-style comparison |
| `round2_` | Neon and technical rendering comparison |
| `round3_` | Symmetrical Cold Cathode and Schematic refinements |

Laser Corona from the third rendering pass became the production treatment. Historical generators are preserved as process artifacts and may refer to the directory layout used during their exploration.
