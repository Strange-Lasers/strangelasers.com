# Strange Lasers singularity studies

These studies keep the outlined Strange Lasers wordmark fixed while exploring six related symbols built from laser paths, event horizons, orbital motion, and bright central cores.

- `oculus`: the closest relative of the selected singularity concept
- `lensing`: parallel beams distorted by a central mass
- `accretion`: a tilted ring crossed by a narrow energy jet
- `eclipse`: a broken event horizon around an interrupted beam
- `vortex`: three beams spiraling into a compact core
- `portal`: nested broken horizons suggesting depth and motion

Each `logo-*.svg` horizontal lockup has a matching square `mark-*.svg`. Run `node generate.mjs` after changing the source geometry or palettes.
