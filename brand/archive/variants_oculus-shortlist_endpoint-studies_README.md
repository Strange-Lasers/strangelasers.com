# Oculus endpoint studies

These studies compare three endpoint treatments using the locked Abyss and Moon Crimson palettes. The arc geometry, iris, glow, wordmark, and layout remain unchanged.

- `current`: circle and square split diagonally across separate arcs
- `directed`: circle source and square detector on the foreground arc
- `parallel`: circle sources and square detectors running left to right on both arcs
- `counterflow`: opposing directions on horizontally aligned foreground and rear arcs
- `paired-circles`: matching circular terminals on the foreground arc

Each treatment includes a horizontal logo and square mark. The original contact sheets compare the first endpoint set; the arc-flow sheets compare Directed, Parallel Flow, and Counterflow. Render previews with librsvg or a browser because ImageMagick's internal SVG decoder misrenders the Gaussian glow filters.
